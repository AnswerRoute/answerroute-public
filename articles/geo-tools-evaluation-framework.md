# GEO Tools Evaluation Framework

GEO tools should be evaluated by whether they can prove how a brand appears in AI answers, which sources support the answer, and what action should happen next.

## Prompt coverage

The first test is prompt coverage. A GEO tool should track core commercial, definition, comparison, and long-tail prompts instead of relying on one broad visibility score.

## Evidence quality

The second test is evidence quality. Useful systems preserve raw answer evidence internally, parse mentions and rankings, and expose public summaries without leaking private raw outputs.

## Citation intelligence

The third test is citation intelligence. AI answers often depend on third-party reviews, community pages, documentation, benchmarks, and comparison content. A GEO workflow should show which sources appear repeatedly.

## Execution support

The fourth test is execution. If a tool only reports that a brand is missing, it is incomplete. It should recommend content assets, internal links, external distribution, and recheck timing.

## The operating loop

AnswerRoute treats GEO as an operating loop: detect, diagnose, publish, distribute, recheck, and record the visibility change.

## Measure the loop

AnswerRoute connects prompts, AI answers, citations, rankings, public assets, distribution records, and rechecks so teams can see whether AI visibility changes after each growth action.
